## 术语约定

### 分类层级

| 中文 | English | 说明 |
|------|---------|------|
| 大类 | category | 一级分类，如 turning/milling |
| 子类 | subcategory | 二级分类，如 milling_end_mill |
| 变型 | variant | 三级分类，如 ball_nose |

### 切削参数标准缩写

| 缩写 | 全称 | 单位 | 说明 |
|------|------|------|------|
| Vc | Cutting Speed | m/min | 切削速度 |
| fz | Feed per Tooth | mm/tooth | 每齿进给量 |
| fn | Feed per Revolution | mm/rev | 每转进给量 |
| ap | Depth of Cut (axial) | mm | 轴向切深 |
| ae | Width of Cut (radial) | mm | 径向切宽 |
| Dc | Cutting Diameter | mm | 切削直径 |
| lc | Cutting Edge Length | mm | 切削刃长 |
| re | Corner Radius | mm | 刀尖圆弧/圆角半径 |
| HRC | Rockwell Hardness C | - | 洛氏硬度 C 标尺 |
| HB | Brinell Hardness | - | 布氏硬度 |

### 材料分类代号（ISO 513）

| 代号 | 类别 | 典型材料 |
|------|------|----------|
| P | 钢 (Steel) | 碳钢、合金钢 |
| M | 不锈钢 (Stainless) | 304、316、17-4PH |
| K | 铸铁 (Cast Iron) | 灰铸铁、球墨铸铁 |
| N | 非铁金属 (Non-ferrous) | 铝合金、铜合金 |
| S | 高温合金 (Superalloy) | 钛合金、Inconel |
| H | 硬材 (Hard Material) | 淬硬钢 >45 HRC |
