# 刀具分类体系总则

## 1. 分类设计原则

### 1.1 三级分类体系

本系统采用**大类 → 子类 → 变型**三级分类，兼顾分组性和细粒度：

| 层级 | 英文字段 | 说明 | 示例 |
|------|----------|------|------|
| 大类 | category | 对应主要加工方式 | milling |
| 子类 | subcategory | 对应具体刀具形态 | milling_end_mill |
| 变型 | variant | 对应功能细分 | ball_nose |

**完整编码格式**：`{category}/{subcategory}/{variant}`

示例：`milling/end_mill/ball_nose` = 铣削/立铣刀/球头

### 1.2 编码规范

- 编码仅用小写字母 + 下划线，禁止特殊字符
- 子类编码：`{大类}_{子类英文}`，如 `milling_end_mill`
- 变型编码：`{子类编码}_{变型英文}`，如 `milling_end_mill_ball_nose`
- 中文命名与 English 编码双轨制：显示用中文，存储用英文编码

### 1.3 为什么是三级而非两级或四级

- **两级不足**：如 `turning → external_roughing`，子类过于细碎，丢失"外圆车刀"的分组
- **四级过细**：如 `turning → external → roughing → heavy`，四级节点间的区别可通过参数（`MaterialSpec.hardness_hrc`、`recommended_parameters`）表达，无需单独建分类节点

## 4. 涂层分类体系

### 4.1 单层涂层

| 涂层 | 硬度 (HV) | 摩擦系数 | 耐热温度 | 典型应用 |
|------|-----------|----------|----------|----------|
| TiN | 2,300 | 0.4 | 600°C | 通用加工，HSS 刀具 |
| TiCN | 3,000 | 0.3 | 450°C | 钢材中速切削 |
| TiAlN | 3,300 | 0.3 | 800°C | 钢材高速干切 |
| AlTiN | 3,500 | 0.3 | 900°C | 硬材高速加工 |
| AlCrN | 3,200 | 0.25 | 1,100°C | 高温合金、锻钢 |
| DLC | 3,000-5,000 | 0.05-0.1 | 350°C | 铝合金、非铁金属 |
| CrN | 1,800 | 0.3 | 700°C | 铜合金、软材料 |

### 4.2 多层/复合涂层

| 涂层 | 结构 | 特点 | 典型应用 |
|------|------|------|----------|
| TiAlN + AlCrN | 纳米多层 | 高硬度+高韧性 | 航空钢材、高温合金 |
| TiAlSiN | 纳米复合 | 极高热硬性 | 淬硬钢高速加工 |
| Al2O3 + TiC | CVD 复合 | 高耐磨+隔热 | 铸铁高速车削 |

### 4.3 涂层选择矩阵

| 工件材料 | 推荐涂层 | 备选涂层 | 说明 |
|----------|----------|----------|------|
| 钢 (P) | TiAlN / AlTiN | TiCN | 高速选 AlTiN |
| 不锈钢 (M) | AlTiN / AlCrN | TiAlN | 需耐热性好的涂层 |
| 铸铁 (K) | TiCN / Al2O3+CVD | TiN | CVD 涂层优势明显 |
| 铝合金 (N) | DLC / 无涂层 | ZrN | 防粘刀是关键 |
| 高温合金 (S) | AlTiN+ / AlCrN | PCD | 需要极耐热涂层 |
| 硬材 (H) | AlTiN / CBN | Al2O3 | 极高热硬度 |

## 5. 刀具材料体系

### 5.1 硬质合金 (Carbide)

ISO 分类（按加工材料分组）：

| ISO 代号 | 颜色标记 | 加工材料 | 硬度趋势 | 韧性趋势 |
|----------|----------|----------|----------|----------|
| P01-P50 | 蓝 | 钢 | P01 最硬 → P50 最韧 | P01 最脆 → P50 最韧 |
| M01-M40 | 黄 | 不锈钢 | M01 最硬 → M40 最韧 | |
| K01-K40 | 红 | 铸铁 | K01 最硬 → K40 最韧 | |
| N01-N30 | 绿 | 非铁金属 | | |
| S01-S30 | 棕 | 高温合金 | | |
| H01-H30 | 白 | 硬材 | | |

**常用牌号对应**：
- P10-P25：钢件精加工/半精加工
- P25-P40：钢件粗加工
- M20-M30：不锈钢通用加工
- K10-K20：铸铁精加工
- K20-K30：铸铁粗加工

### 5.2 高速钢 (HSS)

| 牌号 | 特点 | 典型应用 |
|------|------|----------|
| W6Mo5Cr4V2 (M2) | 通用型高速钢 | 丝锥、钻头、铰刀 |
| W6Mo5Cr4V2Co5 (M35) | 含钴，耐热性提升 | 不锈钢加工用丝锥 |
| W2Mo9Cr4VCo8 (M42) | 高钴，高硬度 | 高硬度材料加工 |

### 5.3 陶瓷 (Ceramic)

| 类型 | 成分 | 特点 | 典型应用 |
|------|------|------|----------|
| 氧化铝基 | Al2O3 + TiC | 高硬度，耐磨损 | 铸铁高速精车 |
| 氮化硅基 | Si3N4 | 高韧性，抗热震 | 铸铁粗车/铣削 |
| 晶须增韧 | Al2O3 + SiCw | 高韧性 | 高温合金加工 |

### 5.4 CBN / PCD 超硬材料

| 材料 | 硬度 (HV) | 特点 | 典型应用 |
|------|-----------|------|----------|
| CBN | 4,000-5,000 | 耐高温，化学稳定性好 | 淬硬钢 (>55HRC) 车削 |
| PCD | 8,000-10,000 | 极高硬度，不耐磨粒 | 铝合金/铜合金高速精车 |

### 5.5 金属陶瓷 (Cermet)

| 类型 | 特点 | 典型应用 |
|------|------|----------|
| TiC 基 | 高耐磨性，低摩擦 | 钢件精加工 |
| TiCN 基 | 兼顾耐磨与韧性 | 钢/铸铁半精加工 |

## 6. 分类体系与现有 CutterType 的映射

### 6.1 现有结构

```python
@dataclass(frozen=True)
class CutterType:
    category: str          # e.g., "end_mill"
    subcategory: Optional[str]  # e.g., "square"
    coating: Optional[str]      # e.g., "TiAlN"  ← 概念上不属于分类
```

### 6.2 调整方案

| 变更项 | 原位置 | 调整后位置 | 原因 |
|--------|--------|------------|------|
| variant 字段 | 无 | CutterType.variant | 新增三级分类 |
| coating | CutterType.coating | MaterialSpec.coating_type | 涂层是材料属性，不是分类属性 |

### 6.3 调整后的结构

```python
@dataclass(frozen=True)
class CutterType:
    category: str          # e.g., "milling"
    subcategory: str       # e.g., "end_mill"
    variant: Optional[str] # e.g., "ball_nose"

@dataclass(frozen=True)
class MaterialSpec:
    substrate: str              # e.g., "carbide_P25"
    coating_type: Optional[str] # e.g., "TiAlN" ← 从 CutterType 移入
    hardness_hrc: Optional[float]
```

### 6.4 编码转换示例

| 现有编码 | 转换后编码 |
|----------|------------|
| `end_mill/square/TiAlN` | `milling/end_mill/square` + coating=`TiAlN` |
| `drill/twist/TiN` | `hole_making/drill/twist` + coating=`TiN` |
| `tap/machine/TiN` | `threading/tap/machine` + coating=`TiN` |
| `reamer/straight/Uncoated` | `hole_making/reamer/straight` + coating=`Uncoated` |
