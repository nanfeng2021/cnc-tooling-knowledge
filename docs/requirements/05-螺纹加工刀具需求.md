# 螺纹加工刀具需求

## 1. 螺纹加工概述

螺纹加工是 CNC 加工中的常见工序，主要有三种方式：攻丝（刀具旋转进给）、螺纹铣削（螺旋插补）和螺纹车削（工件旋转+刀具同步进给）。选择何种方式取决于螺纹规格、精度要求、机床能力和生产批量。

**螺纹标准**：
- 公制螺纹 (ISO)：M8×1.25 等
- 统一螺纹 (UNC/UNF)：1/4-20 等
- 管螺纹 (BSPT/NPT)：G1/2"、R1/4" 等
- 梯形螺纹：Tr20×4 等

## 2. 螺纹加工刀具分类体系

### 2.1 丝锥 (threading_tap)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 机用丝锥 | machine | 机夹使用，高速钢/硬质合金 | CNC 刚性攻丝 |
| 手用丝锥 | hand | 手动操作，高精度 | 修配/小批量 |
| 螺旋槽丝锥 | spiral_flute | 螺旋槽，向前排屑 | 盲孔攻丝 |
| 直槽丝锥 | straight_flute | 直槽，通用 | 通孔攻丝 |
| 螺尖丝锥 | spiral_point | 螺旋尖，向后排屑 | 通孔攻丝（高效） |
| 挤压丝锥 | forming | 无切屑，挤压成形 | 铝合金/软钢盲孔 |
| 管螺纹丝锥 | pipe | 管螺纹专用 | G/R 管螺纹 |
| 锥管螺纹丝锥 | taper_pipe | 锥管螺纹专用 | NPT/BSPT 锥管 |

### 2.2 板牙 (threading_die)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 圆板牙 | round_die | 手动/机用，外螺纹 | 外螺纹加工 |
| 六角板牙 | hex_die | 扳手驱动 | 现场修配 |

### 2.3 螺纹铣刀 (threading_mill)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 单刃螺纹铣刀 | single_point | 一把刀可加工多种螺距 | 多品种小批量 |
| 多刃螺纹铣刀 | multi_point | 多刃高效，固定螺距 | 大批量高效加工 |
| 整体螺纹铣刀 | solid | 整体硬质合金 | 高精度小径螺纹 |
| 可转位螺纹铣刀 | indexable | 机夹刀片，大径螺纹 | 大径螺纹高效加工 |

### 2.4 螺纹车刀 (threading_turning)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 外螺纹车刀 | external | 车削外螺纹 | 螺栓、丝杠等 |
| 内螺纹车刀 | internal | 车削内螺纹 | 螺母、内螺纹孔 |
| 管螺纹车刀 | pipe | 车削管螺纹 | 管接头 |

## 4. 螺纹加工应用场景

### 4.1 螺纹加工方式选择决策

```
螺纹加工方式选择
├── 机床是车床？ → 螺纹车削
├── 机床是加工中心？
│   ├── 螺纹规格多？→ 螺纹铣削（一把刀多规格）
│   ├── 盲孔？
│   │   ├── 精度要求高？→ 螺旋槽丝锥 / 挤压丝锥
│   │   └── 通用？→ 螺旋槽丝锥
│   ├── 通孔？
│   │   └── 螺尖丝锥（高效排屑）
│   └── 大径螺纹(>M30)？→ 螺纹铣削 / 可转位螺纹铣
└── 手动修配？→ 手用丝锥 / 板牙
```

### 4.2 底孔直径推荐对照表

| 螺纹规格 | 螺距 | 底孔直径(切削) | 底孔直径(挤压) |
|----------|------|----------------|----------------|
| M3 | 0.5 | 2.5 | 2.75 |
| M4 | 0.7 | 3.3 | 3.60 |
| M5 | 0.8 | 4.2 | 4.55 |
| M6 | 1.0 | 5.0 | 5.45 |
| M8 | 1.25 | 6.8 | 7.40 |
| M8 | 1.0 | 7.0 | 7.45 |
| M10 | 1.5 | 8.5 | 9.30 |
| M10 | 1.25 | 8.8 | 9.40 |
| M12 | 1.75 | 10.2 | 11.15 |
| M12 | 1.5 | 10.5 | 11.30 |
| M16 | 2.0 | 14.0 | 15.40 |
| M20 | 2.5 | 17.5 | 19.20 |

**计算公式**：
- 切削丝锥：底孔 ≈ 公称直径 - 螺距
- 挤压丝锥：底孔 ≈ 公称直径 - 0.5×螺距（需查表精确值）

## 7. 数据模型映射

### 7.1 螺纹刀具在数据模型中的表达

```
CutterType:
  category = "threading"
  subcategory = "threading_tap"
  variant = "spiral_flute"

MaterialSpec:
  substrate = "hss_cobalt"     # 含钴高速钢
  coating_type = "PVD_TiN"
  hardness_hrc = 67.0

GeometryParams (基础):
  diameter = 8.0              # M8
  length = 70.0               # 总长
  flute_length = 30.0         # 槽长
  number_of_flutes = 3        # 3 槽
  helix_angle = 35.0          # 螺旋槽丝锥
  corner_radius = 0.0

TappingGeometry (新增扩展值对象):
  thread_spec = "M8x1.25"     # 螺纹规格
  tap_tolerance = "6H"        # 公差等级
  flute_type = "spiral"       # 槽型
  chamfer_length = 4          # 切削锥长(牙数)
```

### 7.2 扩展需求摘要

- 新增 `thread_spec` 字段：螺纹规格（M8×1.25、G1/2"等），是螺纹刀具的核心属性
- 新增 `tap_tolerance` 字段：丝锥公差等级（4H/6H等）
- 新增 `pitch_range` 字段：螺纹铣刀/车刀的可加工螺距范围
- 新增 `thread_angle` 字段：螺纹车刀的刀尖角（60°/55°/30°）
- 新增 `TappingGeometry`、`ThreadingMillGeometry`、`ThreadingTurningGeometry` 值对象
- 详细映射方案见 [10-数据模型映射与扩展需求](10-数据模型映射与扩展需求.md)
