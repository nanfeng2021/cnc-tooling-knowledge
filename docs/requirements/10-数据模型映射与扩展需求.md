# 数据模型映射与扩展需求

## 1. 现有数据模型分析

### 1.1 CutterType（刀具分类）

```python
@dataclass(frozen=True)
class CutterType:
    category: str               # e.g., "end_mill"
    subcategory: Optional[str]  # e.g., "square"
    coating: Optional[str]      # e.g., "TiAlN"
```

**不足**：
- 缺少 `variant`（变型）层级，无法表达三级分类
- `coating` 放在此处概念错误 — 涂层是材料属性，不是分类属性
- `category` 值为 `end_mill` 等，混淆了大类和子类
- 无 ISO 大类编码（turning/milling 等）

### 1.2 MaterialSpec（材料规格）

```python
@dataclass(frozen=True)
class MaterialSpec:
    substrate: str               # e.g., "carbide", "hss"
    coating_type: Optional[str]  # e.g., "TiAlN", "TiN"
    hardness_hrc: Optional[float]
```

**不足**：
- `substrate` 无 ISO 分类代码（如 P25、K20）
- 无材料牌号字段（如 "45#"、"304"）
- `coating_type` 存在此处正确，但与 CutterType.coating 冗余

### 1.3 GeometryParams（几何参数）

```python
@dataclass(frozen=True)
class GeometryParams:
    diameter: float           # mm
    length: float             # mm
    flute_length: float       # mm
    number_of_flutes: int
    helix_angle: float = 30.0  # degrees
    corner_radius: float = 0.0 # mm
```

**不足**：
- **铣削专属**：`flute_length`、`helix_angle`、`corner_radius` 对车削/齿轮刀具无意义
- 缺少各类别核心参数：钻头顶角、铰刀公差、镗刀孔径范围、齿轮模数等
- 无法区分整体刀具与可转位刀具

### 1.4 Cutter（聚合根）

```python
@dataclass
class Cutter:
    id: UUID
    name: str
    cutter_type: CutterType
    material: MaterialSpec
    geometry: GeometryParams
    recommended_parameters: dict[str, float]
    usage_guidelines: list[str]
    compatible_materials: list[str]
    created_at: datetime
    updated_at: datetime
    embedding_vector: Optional[list[float]]
```

**不足**：
- 无制造商信息（manufacturer_id）
- 无厂商型号（model_number）
- 无应用场景（applicable_scenarios）
- 无类别专属几何参数
- `compatible_materials` 用简单字符串，无 ISO 分类结构

## 2. 扩展方案

### 2.1 CutterType 扩展

```python
@dataclass(frozen=True)
class CutterType:
    category: str               # 大类: "turning", "milling", "hole_making",
                                 #       "threading", "gear_cutting"
    subcategory: str            # 子类: "end_mill", "drill", "tap", "hob" 等
    variant: Optional[str]      # 变型: "ball_nose", "spiral_flute", "standard" 等

    @classmethod
    def from_string(cls, value: str) -> "CutterType":
        """从 'category/subcategory/variant' 格式解析"""
        parts = value.split("/")
        return cls(
            category=parts[0],
            subcategory=parts[1] if len(parts) > 1 else "",
            variant=parts[2] if len(parts) > 2 else None,
        )
```

**变更说明**：
- `coating` 字段移至 `MaterialSpec.coating_type`（概念修正）
- 新增 `variant` 字段
- `category` 改为 ISO 大类编码
- `subcategory` 改为必填
- 保留 `from_string` 解析方法

**编码转换映射**：

| 现有编码 | 转换后编码 | 说明 |
|----------|------------|------|
| `end_mill/square/TiAlN` | `milling/end_mill/square` | coating 移至 MaterialSpec |
| `drill/twist/TiN` | `hole_making/drill/twist` | coating 移至 MaterialSpec |
| `reamer/straight/Uncoated` | `hole_making/reamer/straight` | coating 移至 MaterialSpec |
| `tap/machine/TiN` | `threading/tap/machine` | coating 移至 MaterialSpec |

### 2.2 MaterialSpec 扩展

```python
@dataclass(frozen=True)
class MaterialSpec:
    substrate: str               # "carbide_P25", "hss", "cbn", "ceramic"
    coating_type: Optional[str]  # "TiAlN", "TiN", "AlCrN", "DLC", "Uncoated"
    hardness_hrc: Optional[float]
    iso_class: Optional[str]     # 新增: "P25", "M20", "K10", "S10"
    material_grade: Optional[str] # 新增: "YB6315", "4325", "KCP10"

    @property
    def description(self) -> str:
        parts = [self.substrate]
        if self.coating_type:
            parts.append(f"with {self.coating_type} coating")
        if self.hardness_hrc:
            parts.append(f"({self.hardness_hrc} HRC)")
        return " ".join(parts)
```

**变更说明**：
- 新增 `iso_class`：ISO 513 分类代码（P25/M20/K10 等）
- 新增 `material_grade`：厂商材质牌号
- `coating_type` 保留（涂层本就属于材料属性）

### 2.3 类别专属几何参数

采用**基础参数 + 可选扩展**策略，保持向后兼容：

```python
# 基础参数保持不变
@dataclass(frozen=True)
class GeometryParams:
    diameter: float
    length: float
    flute_length: float = 0.0
    number_of_flutes: int = 1
    helix_angle: float = 0.0
    corner_radius: float = 0.0


# 铣削专属参数（与现有 GeometryParams 匹配度最高）
@dataclass(frozen=True)
class MillingGeometry:
    shank_type: Optional[str]        # "straight", "BT40", "CAT50", "HSK63"
    insert_size: Optional[str]       # 可转位刀片尺寸 "08", "11", "12"
    pitch: Optional[str]             # "fine", "medium", "coarse"（面铣刀）
    lead_angle: Optional[float]      # 主偏角 45°/60°/75°/90°（面铣刀）


# 车削专属参数
@dataclass(frozen=True)
class TurningGeometry:
    insert_shape: str                # "C", "D", "S", "T", "V", "R", "W" 等
    insert_ic: float                 # 内切圆直径 mm
    relief_angle: str                # "N", "B", "C", "E", "P"
    holder_section: Optional[str]    # "25×25", "32×20", "Φ20" 等
    hand: str                        # "R", "L", "N"
    overhang: Optional[float]        # 悬伸长度 mm


# 钻削专属参数
@dataclass(frozen=True)
class DrillingGeometry:
    point_angle: float               # 顶角 90°/118°/135°/140°
    web_thickness: Optional[float]   # 横刃厚 mm


# 铰削专属参数
@dataclass(frozen=True)
class ReamingGeometry:
    tolerance_class: str             # "H6", "H7", "H8" 等
    chamfer_angle: Optional[float]   # 导向锥角 °
    guide_length: Optional[float]    # 导向长度 mm
    flute_type: str                  # "straight", "spiral"


# 镗削专属参数
@dataclass(frozen=True)
class BoringGeometry:
    bore_diameter_min: float         # 最小镗孔直径 mm
    bore_diameter_max: float         # 最大镗孔直径 mm
    adjustment_precision: Optional[float]  # 调节精度 mm
    boring_head_type: str            # "rough", "fine", "micro", "double"


# 丝锥专属参数
@dataclass(frozen=True)
class TappingGeometry:
    thread_spec: str                 # "M8x1.25", "G1/2", "NPT1/4"
    tap_tolerance: Optional[str]     # "4H", "6H"
    flute_type: str                  # "straight", "spiral", "spiral_point", "forming"
    chamfer_length: Optional[int]    # 切削锥长(牙数)


# 螺纹铣削专属参数
@dataclass(frozen=True)
class ThreadingMillGeometry:
    pitch_range: str                 # "0.5-3.0" mm
    min_thread_dia: Optional[float]  # 最小加工螺纹直径 mm
    max_thread_dia: Optional[float]  # 最大加工螺纹直径 mm


# 螺纹车削专属参数
@dataclass(frozen=True)
class ThreadingTurningGeometry:
    pitch_range: str                 # "0.5-6.0" mm
    thread_angle: float              # 60°(公制)/55°(BSP)/30°(梯形)
    hand: str                        # "R", "L"


# 滚刀专属参数
@dataclass(frozen=True)
class GearHobGeometry:
    module: float                    # 模数 mm
    pressure_angle: float            # 压力角 ° (标准20°)
    number_of_starts: int            # 头数 1/2/3
    hand: str                        # "right", "left"
    outside_diameter: Optional[float] # 外径 mm
    bore_diameter: Optional[float]   # 孔径 mm
    precision_grade: str             # "AA", "A", "B", "C"
    flute_type: str                  # "straight", "spiral"


# 插齿刀专属参数
@dataclass(frozen=True)
class GearShaperGeometry:
    module: float                    # 模数 mm
    number_of_teeth: int             # 齿数
    pitch_diameter: float            # 分度圆直径 mm
    bore_diameter: Optional[float]   # 内孔直径 mm
    pressure_angle: float            # 压力角 °
    precision_grade: str             # "AA", "A", "B", "C"


# 剃齿刀专属参数
@dataclass(frozen=True)
class GearShavingGeometry:
    module: float                    # 模数 mm
    number_of_teeth: int             # 齿数
    pitch_diameter: float            # 分度圆直径 mm
    helix_angle: Optional[float]     # 螺旋角 °
```
