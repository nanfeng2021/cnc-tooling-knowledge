# 分类浏览与筛选需求

## 1. 页面概述

- **访问路径**：`/catalog`
- **页面目标**：通过逐级筛选浏览全部刀具库，支持多维度筛选和分页

## 2. 页面布局结构

从上到下共 6 层：

```
① 主分类 Tab 行       [全部] [车削] [铣削] [孔加工] [螺纹] [齿轮]
② 子分类按钮行        [全部] [外圆车刀] [内孔车刀] ... (选中主分类时显示)
③ 筛选器区域
   ├── 厂商: <Select 下拉>
   ├── 变型: [全部] [粗车] [精车] ... (选中子分类时显示)
   └── 材料: [P 钢] [M 不锈钢] [K 铸铁] [N 非铁] [S 高温] [H 硬材]
④ 结果统计           共 48 条，当前第 1-10 条
⑤ 刀具卡片网格       3 列响应式
⑥ 分页控件           [◀ 上一页] 1 2 3 ... 5 [下一页 ▶]  每页 10 条
```

## 3. 筛选维度设计

### 3.1 主分类（category）

- **已有**，保持不变
- 渲染为 Button Group
- 选项：全部 + 5 大类（车削/铣削/孔加工/螺纹/齿轮）
- 选中态：`variant="default"`，非选中态：`variant="outline"`

### 3.2 子分类（subcategory）

- **已有**，保持不变
- 仅在选中主分类时显示
- 渲染为 Button Group（`variant="secondary"/ghost`）
- 选项：全部 + 当前主分类下的子分类列表

### 3.3 厂商（manufacturer）— 新增

- 渲染为 `<Select>` 下拉组件
- 数据源：`manufacturers`（12 家厂商）
- 选项：「全部厂商」+ 所有厂商
- 值绑定：`selectedManufacturer`（manufacturer_id 或 null）
- 始终显示（不依赖其他筛选条件）

### 3.4 变型（variant）— 新增

- 渲染为 Button Group
- 仅在选中子分类时显示
- 数据源：`currentSubcategory.variants`
- 选项：「全部」+ 当前子分类下的变型列表
- 值绑定：`selectedVariant`（variant 编码或 null）

### 3.5 ISO 材料类别（iso_class）— 新增

- 渲染为可点击的 Badge/Button 组
- 始终显示（不依赖其他筛选条件）
- 数据源：`ISO_CLASSES` 常量（P/M/K/N/S/H 六类）
- 每个按钮使用对应的 ISO 颜色样式
- 选项：「全部材料」+ 6 个 ISO 类别
- 值绑定：`selectedIsoClass`（ISO 代码或 null）
- 当前设计为**单选**

## 4. 分页设计

### 4.1 基本参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 默认每页条数 | 10 | `pageSize = 10` |
| 页码基准 | 0-based (store) / 1-based (URL + 显示) | |

### 4.2 显示信息

- 结果统计：`共 {total} 条，当前第 {start}–{end} 条`
  - `start = page * pageSize + 1`
  - `end = Math.min((page + 1) * pageSize, total)`
- 分页导航：`[◀ 上一页] 1 2 ... N [下一页 ▶]`
- 总页数显示：`共 {totalPages} 页`

### 4.3 页码省略号

- 当总页数 > 7 时，使用 `...` 省略中间页码
- 始终显示首页和末页
- 当前页左右各显示 siblingCount(默认 1) 个页码

### 4.4 边界处理

- `total === 0`：不显示分页控件
- 仅 1 页：仅显示总数信息
- URL 中 page 超出范围时，自动修正为最后一页

## 5. URL 参数同步策略

### 5.1 同步参数

| URL 参数 | Store 字段 | 示例 | 说明 |
|----------|-----------|------|------|
| `category` | selectedCategory | turning | 主分类编码 |
| `subcategory` | selectedSubcategory | turning_external | 子分类编码 |
| `variant` | selectedVariant | roughing | 变型编码 |
| `manufacturer_id` | selectedManufacturer | mfr-sandvik | 厂商 ID |
| `iso_class` | selectedIsoClass | P | ISO 材料代码 |
| `page` | page | 1 | 页码（URL 中 1-based） |

### 5.2 同步方向

- **URL → Store（初始化）**：页面加载时从 URL 读取参数初始化 store
- **Store → URL（用户操作）**：筛选/翻页变更时更新 URL（`replace: true`）
- `null` 值删除对应 URL 参数，保持 URL 清洁

### 5.3 同步时序

```
用户点击筛选 → store.setState → useEffect 触发 fetchCutters → 渲染
              ↘ navigate(replace) 更新 URL

用户打开 URL → useEffect 读 params → store.setState → fetchCutters → 渲染
```

## 6. 交互规则

| 操作 | 副作用 |
|------|--------|
| 主分类变更 | 重置 subcategory=null, variant=null, page=0 |
| 子分类变更 | 重置 variant=null, page=0 |
| 厂商变更 | 重置 page=0 |
| 变型变更 | 重置 page=0 |
| ISO 材料变更 | 重置 page=0 |
| 翻页 | 仅更新 page，不重置其他筛选 |
| 清空筛选 | 所有筛选归 null，page=0 |

## 7. 加载态与空态

- **加载中**：显示 "加载中..." 文字
- **无结果（有筛选条件）**："当前筛选条件下无匹配刀具，请调整筛选条件"
- **无结果（无筛选条件）**："暂无刀具数据"

## 8. 后端 API 参数约定

```
GET /api/cutters
  ?category=turning          # 可选，主分类
  &subcategory=turning_external  # 可选，子分类
  &variant=roughing          # 可选，变型
  &manufacturer_id=mfr-sandvik  # 可选，厂商 ID
  &iso_class=P               # 可选，ISO 材料代码
  &limit=10                  # 可选，每页条数（默认 20）
  &offset=0                  # 可选，偏移量
```

响应格式：

```json
{
  "items": [...],
  "total": 48,
  "limit": 10,
  "offset": 0
}
```
