# 工件材料体系需求

## 1. 材料分类标准

### 1.1 ISO 513 分类体系

ISO 513 将工件材料按切削加工特性分为 6 大类：

| 代号 | 颜色标记 | 类别 | 切削特性 |
|------|----------|------|----------|
| P | 蓝 | 钢 (Steel) | 一般良好，高硬度需特殊刀具 |
| M | 黄 | 不锈钢 (Stainless) | 加工硬化倾向，低 Vc 高 fz |
| K | 红 | 铸铁 (Cast Iron) | 粉碎性切屑，高 Vc 低 fz |
| N | 绿 | 非铁金属 (Non-ferrous) | 高 Vc，易粘刀 |
| S | 棕 | 高温合金 (Superalloy) | 极难加工，低 Vc，需锋利刀具 |
| H | 白 | 硬材 (Hard Material) | 需 CBN/陶瓷刀具 |

### 1.2 子级分类编码

采用 `大类_子级` 格式，如 `P_steel`、`P_alloy_steel`：

| 代号 | 子级 | 说明 |
|------|------|------|
| P_carbon | 碳钢 | 低碳/中碳/高碳钢 |
| P_alloy | 合金钢 | 低/中/高合金钢 |
| P_tool | 工具钢 | 冷作/热作/塑料模具钢 |
| M_austenitic | 奥氏体不锈钢 | 304/316 等 |
| M_martensitic | 马氏体不锈钢 | 410/420/440C 等 |
| M_duplex | 双相不锈钢 | 2205 等 |
| K_gray | 灰铸铁 | HT200/HT250 |
| K_ductile | 球墨铸铁 | QT450/QT600 |
| K_malleable | 可锻铸铁 | |
| N_aluminum | 铝合金 | 6061/7075 等 |
| N_copper | 铜合金 | 黄铜/青铜 |
| S_nickel | 镍基高温合金 | Inconel/GH 系列 |
| S_titanium | 钛合金 | TC4/TA1 等 |
| S_cobalt | 钴基高温合金 | |
| H_hardened | 淬硬钢 | >45 HRC |
| H_chilled | 冷硬铸铁 | |

## 2. 各大类材料详解

### 2.1 P 类 — 钢 (Steel)

#### 碳钢 (P_carbon)

| 牌号 | 硬度 (HB) | 特点 | 切削加工性 |
|------|-----------|------|-----------|
| Q235 | 100-150 | 低碳钢，软 | 良好，易粘刀 |
| 20# | 150-170 | 低碳钢 | 良好 |
| 45# | 170-230 | 中碳钢，最常用 | 良好，典型加工材料 |
| 65Mn | 230-280 | 高碳钢，较硬 | 一般，需锋利刀具 |

#### 合金钢 (P_alloy)

| 牌号 | 硬度 (HB) | 特点 | 切削加工性 |
|------|-----------|------|-----------|
| 40Cr | 200-250 | 常用合金钢 | 良好 |
| 42CrMo | 220-280 | 高强度 | 一般 |
| 20CrMnTi | 180-230 | 渗碳钢 | 良好 |
| GCr15 | 180-250 | 轴承钢 | 一般 |

#### 工具钢 (P_tool)

| 牌号 | 硬度 (HRC) | 特点 | 切削加工性 |
|------|------------|------|-----------|
| Cr12MoV | 58-62 | 冷作模具钢 | 退火后加工，淬硬后归 H 类 |
| H13 | 44-52 | 热作模具钢 | 退火后一般 |
| P20 | 28-36 | 塑料模具钢 | 良好，预硬态加工 |

### 2.2 M 类 — 不锈钢 (Stainless)

#### 奥氏体不锈钢 (M_austenitic)

| 牌号 | 硬度 (HB) | 特点 | 切削加工性 |
|------|-----------|------|-----------|
| 304 | 150-200 | 最常用不锈钢 | 较差，加工硬化 |
| 316 | 150-200 | 含钼，耐腐蚀 | 差 |
| 316L | 150-200 | 超低碳 | 差 |
| 17-4PH | 280-380 | 沉淀硬化 | 一般(固溶态)/差(时效态) |

**切削要点**：低 Vc、高 fz、锋利刀片、充分冷却、避免在硬化层切削

#### 马氏体不锈钢 (M_martensitic)

| 牌号 | 硬度 (HRC) | 特点 | 切削加工性 |
|------|------------|------|-----------|
| 410 | 150-200 HB | 通用马氏体 | 一般 |
| 420 | 200-250 HB | 较高强度 | 一般 |
| 440C | 55-60 HRC | 高硬度 | 差，归 H 类 |

### 2.3 K 类 — 铸铁 (Cast Iron)

| 牌号 | 硬度 (HB) | 特点 | 切削加工性 |
|------|-----------|------|-----------|
| HT200 | 170-240 | 灰铸铁，最常用 | 良好，粉碎性切屑 |
| HT250 | 190-260 | 灰铸铁，高强度 | 良好 |
| QT450-10 | 150-200 | 球墨铸铁 | 一般，韧性大 |
| QT600-3 | 200-270 | 球墨铸铁，高强度 | 一般 |

**切削要点**：高 Vc、中 fz、CVD 涂层优势、无需切削液（干切）

### 2.4 N 类 — 非铁金属 (Non-ferrous)

| 牌号 | 硬度 (HB) | 特点 | 切削加工性 |
|------|-----------|------|-----------|
| 6061 | 60-100 | 通用铝合金 | 极好，高 Vc |
| 7075 | 120-160 | 高强度铝合金 | 良好 |
| LY12 | 100-130 | 硬铝合金 | 良好 |
| H62 | 120-160 | 黄铜 | 极好 |
| QAL9-4 | 150-200 | 铝青铜 | 良好 |

**切削要点**：极高 Vc（300-2000 m/min）、DLC/无涂层防粘刀、大前角、大螺旋角

### 2.5 S 类 — 高温合金 (Superalloy)

| 牌号 | 硬度 (HRC) | 特点 | 切削加工性 |
|------|------------|------|-----------|
| Inconel 718 | 35-45 | 镍基，最常用高温合金 | 极差 |
| GH4169 | 35-45 | 国产镍基 | 极差 |
| TC4 (Ti-6Al-4V) | 30-38 | 钛合金，最常用 | 很差 |
| TA1 | 150-200 HB | 工业纯钛 | 差 |

**切削要点**：
- 极低 Vc（30-120 m/min）
- 需锋利刀片，正前角
- 充分冷却（内冷优先）
- 钛合金：化学活性高，避免摩擦

### 2.6 H 类 — 硬材 (Hard Material)

| 类型 | 硬度 (HRC) | 特点 | 切削加工性 |
|------|------------|------|-----------|
| 淬硬钢 | 45-65 | 淬火/渗碳后 | 极差，需 CBN/陶瓷 |
| 冷硬铸铁 | 50-60 HRC | 轧辊等 | 极差 |

**切削要点**：CBN/陶瓷刀具、低 fz、中 Vc、干切或微量润滑

## 3. 材料与刀具匹配矩阵

### 3.1 刀片材质 + 涂层 + Vc 范围

| 工件材料 | 推荐刀片材质 | 推荐涂层 | Vc 范围 (m/min) | 备注 |
|----------|-------------|----------|-----------------|------|
| 碳钢 (P_carbon) | 硬质合金 P10-P25 | TiAlN | 150-300 | 通用加工 |
| 合金钢 (P_alloy) | 硬质合金 P20-P40 | TiAlN/AlTiN | 100-250 | 粗加工选 P35+ |
| 不锈钢 (M) | 硬质合金 M20-M30 | AlTiN/AlCrN | 80-200 | 需锋利刀片 |
| 灰铸铁 (K_gray) | 硬质合金 K10-K20 | TiCN/Al2O3(CVD) | 150-400 | CVD 涂层优势 |
| 球墨铸铁 (K_ductile) | 硬质合金 K20-K30 | TiCN | 100-300 | 类似钢件加工 |
| 铝合金 (N_aluminum) | 硬质合金/PCD | 无涂层/DLC | 300-2000 | PCD 更佳 |
| 铜合金 (N_copper) | 硬质合金 | 无涂层/DLC | 200-800 | 防粘刀 |
| 钛合金 (S_titanium) | 硬质合金 S05-S15 | AlTiN+ | 30-80 | 充分冷却 |
| 镍基合金 (S_nickel) | 硬质合金 S05-S10 | AlTiN+ | 30-60 | 陶瓷可选 |
| 淬硬钢 (H, >55HRC) | CBN | CBN | 80-250 | 以车代磨 |

## 4. 数据模型映射

### 4.1 现有 compatible_materials 的不足

当前 `compatible_materials` 使用简单字符串列表：

```python
compatible_materials: list[str]  # ["steel", "aluminum", "stainless_steel"]
```

**问题**：
- 无 ISO 分类结构，无法按 P/M/K/N/S/H 过滤
- 无具体牌号，"steel" 无法区分 45# 和 Inconel
- 无硬度信息，相同材料不同硬度差异巨大

### 4.2 升级方案

采用 ISO 分类代码 + 材料牌号双编码：

```python
# 方案一：结构化材料引用
compatible_materials: list[MaterialRef]

@dataclass(frozen=True)
class MaterialRef:
    iso_class: str        # "P_carbon"
    grade: Optional[str]  # "45#", "304"
    hardness_max: Optional[float]  # 最大适用硬度 HRC
```

### 4.3 编码格式

| 格式 | 示例 | 说明 |
|------|------|------|
| `{大类}` | `P` | 仅大类 |
| `{大类}_{子级}` | `P_carbon` | 大类+子级 |
| `{大类}_{子级}_{牌号}` | `P_carbon_45` | 完整编码 |

**搜索场景**：
- 用户输入"45号钢" → 解析为 `P_carbon_45` → 匹配 compatible_materials 中包含 `P_carbon` 或 `P_carbon_45` 的刀具
- 用户输入"不锈钢" → 解析为 `M` → 匹配 compatible_materials 中包含 `M` 或其子级的刀具
