# 齿轮加工刀具需求

## 1. 齿轮加工概述

齿轮加工是机械制造中的专业领域，涉及滚齿、插齿、剃齿、铣齿、磨齿等工艺。齿轮刀具的设计与标准齿轮参数（模数、压力角、齿数等）紧密关联。

**齿轮参数基础**：
- 模数 (module, m)：齿轮齿大小的基本参数，单位 mm
- 压力角 (pressure angle, α)：啮合角，标准 20°
- 齿数 (z)：齿轮的齿数
- 分度圆直径 (d) = m × z

**适用机床**：
- 滚齿机：齿轮滚刀
- 插齿机：插齿刀
- 剃齿机：剃齿刀
- 齿轮加工中心：多工艺集成

## 2. 齿轮加工刀具分类体系

### 2.1 滚刀 (gear_hob)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 齿轮滚刀 | standard | 标准渐开线齿轮滚刀 | 批量圆柱齿轮加工 |
| 剃前滚刀 | pre_shave | 留剃齿余量 | 滚齿→剃齿工序链 |
| 磨前滚刀 | pre_grind | 留磨削余量 | 滚齿→磨齿工序链 |
| 蜗轮滚刀 | worm_wheel | 专用蜗轮滚刀 | 蜗轮副加工 |
| 链轮滚刀 | sprocket | 链轮齿形滚刀 | 链轮加工 |
| 渐开线花键滚刀 | spline | 花键齿形滚刀 | 渐开线花键加工 |

### 2.2 插齿刀 (gear_shaper)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 盘形插齿刀 | disc | 盘状，安装于插齿机主轴 | 外齿轮插齿 |
| 碗形插齿刀 | bowl | 碗状，螺母压紧 | 内齿轮/联轴齿轮 |
| 锥柄插齿刀 | taper_shank | 锥柄，直接插入主轴 | 内齿轮插齿 |
| 筒形插齿刀 | hub | 筒状，大直径 | 大型内齿轮 |

### 2.3 剃齿刀 (gear_shaving)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 盘形剃齿刀 | disc | 最常用，齿面开槽 | 外齿轮精加工 |
| 齿条形剃齿刀 | rack | 齿条形 | 大批量齿轮精加工 |

### 2.4 齿轮铣刀 (gear_milling_cutter)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 盘形齿轮铣刀 | disc | 成形铣削，按模数/号数选刀 | 单件小批量齿轮 |
| 指形齿轮铣刀 | finger | 指状，大模数齿轮 | 大模数齿轮单件加工 |

### 2.5 锥齿轮刀具 (gear_bevel)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 弧齿锥齿轮铣刀 | spiral | 弧齿锥齿轮专用 | 汽车差速器齿轮 |
| 直齿锥齿轮刨刀 | straight | 刨削直齿锥齿轮 | 直齿锥齿轮加工 |

## 3. 齿轮刀具几何参数需求

### 3.1 滚刀参数

| 参数 | 编码 | 单位 | 范围 | 说明 |
|------|------|------|------|------|
| 模数 | module | mm | 0.5-40 | 齿轮基本参数 |
| 压力角 | pressure_angle | ° | 20°(标准)/14.5°/25° | 啮合角 |
| 头数 | number_of_starts | - | 1/2/3 | 单头精度高，多头效率高 |
| 旋向 | hand | - | right/left | 右旋/左旋 |
| 外径 | outside_diameter | mm | - | 滚刀外径 |
| 孔径 | bore_diameter | mm | - | 安装孔径 |
| 容屑槽数 | number_of_flutes | - | 8-16 | 直槽/螺旋槽 |
| 精度等级 | precision_grade | - | AA/A/B/C | AA 最高精度 |
| 刃沟类型 | flute_type | - | straight/spiral | 直槽/螺旋槽 |

**头数选择**：

| 头数 | 特点 | 典型应用 |
|------|------|----------|
| 1 | 最高精度 | 精密齿轮 |
| 2 | 效率×2，精度略降 | 通用齿轮 |
| 3 | 效率×3，精度降低 | 粗滚齿 |

**精度等级**：

| 等级 | 适用齿轮精度 | 说明 |
|------|-------------|------|
| AA | 5-6 级 | 精密齿轮 |
| A | 6-7 级 | 通用齿轮 |
| B | 7-8 级 | 一般齿轮 |
| C | 8-9 级 | 粗加工 |

### 3.2 插齿刀参数

| 参数 | 编码 | 单位 | 说明 |
|------|------|------|------|
| 模数 | module | mm | 齿轮基本参数 |
| 齿数 | z | - | 插齿刀齿数 |
| 分度圆直径 | pitch_diameter | mm | d = m × z |
| 内孔直径 | bore_diameter | mm | 安装孔径 |
| 压力角 | pressure_angle | ° | 标准为 20° |
| 精度等级 | precision_grade | - | AA/A/B/C |
| 前角 | rake_angle | ° | 通常 5° |
| 后角 | clearance_angle | ° | 通常 6° |

### 3.3 剃齿刀参数

| 参数 | 编码 | 单位 | 说明 |
|------|------|------|------|
| 模数 | module | mm | |
| 齿数 | z | - | |
| 分度圆直径 | pitch_diameter | mm | |
| 螺旋角 | helix_angle | ° | 剃齿刀螺旋角 |
| 齿面槽型 | slot_type | - | 开槽形式 |

### 3.4 与现有 GeometryParams 的适配性

齿轮刀具几何参数与现有 `GeometryParams` 完全不同，大部分参数无法对应：

| 参数 | GeometryParams | 适配性 | 说明 |
|------|----------------|--------|------|
| diameter | 部分适用 | 滚刀外径 | 非切削直径 |
| length | 部分适用 | 滚刀宽度 | 非总长 |
| flute_length | 不适用 | | 齿轮刀具无此概念 |
| number_of_flutes | 部分适用 | 容屑槽数 | 含义不同 |
| helix_angle | 不适用 | | 滚刀用旋向和头数 |
| corner_radius | 不适用 | | |

## 4. 齿轮加工应用场景

### 4.1 齿轮加工工序链

| 目标精度 | 工序链 | 说明 |
|----------|--------|------|
| 8-9 级 | 滚齿 | 一般精度齿轮 |
| 7-8 级 | 滚齿 → 剃齿 | 热处理前精加工 |
| 6-7 级 | 滚齿 → 热处理 → 磨齿 | 高精度硬齿面齿轮 |
| 5-6 级 | 滚齿(AA级) → 磨齿 | 精密齿轮 |

### 4.2 机床与刀具匹配

| 机床类型 | 可用刀具 | 加工能力 |
|----------|----------|----------|
| 滚齿机 | 齿轮滚刀 | 批量圆柱齿轮（最常用） |
| 插齿机 | 插齿刀 | 内齿轮/台阶齿轮/联轴齿轮 |
| 剃齿机 | 剃齿刀 | 齿面精加工（热处理前） |
| 磨齿机 | 砂轮 | 齿面精加工（热处理后） |
| 加工中心 | 齿轮铣刀 | 单件小批量齿轮 |

### 4.3 滚齿 vs 插齿选择

| 对比项 | 滚齿 | 插齿 |
|--------|------|------|
| 齿轮类型 | 外齿轮 | 外齿轮 + 内齿轮 |
| 生产效率 | 高（连续切削） | 较低（往复运动） |
| 阶梯齿轮 | 不便 | 可加工 |
| 内齿轮 | 不可 | 可加工 |
| 齿向修形 | 难 | 容易 |
| 典型批量 | 大批量 | 中小批量/特殊齿轮 |

### 4.4 切削参数推荐

|----------|------------|-------------|------|

| 钢 (P, >250HB) | 25-50 | 0.8-2.5 | HSS 滚刀 |
| 铸铁 (K) | 30-60 | 1.5-4.0 | |

## 5. 齿轮刀具型号规则

### 5.1 滚刀型号

**格式**：`精度 模数 压力角 旋向 头数 外径 孔径`

示例：`AA m2 α20° R 1 Φ63 Φ27`

| 段 | 含义 | 示例值 |
|----|------|--------|
| AA | 精度等级 | AA/A/B/C |
| m2 | 模数 2mm | |
| α20° | 压力角 | 标准为 20° |
| R | 右旋 | R=右旋, L=左旋 |
| 1 | 单头 | 1/2/3 头 |
| Φ63 | 外径 63mm | |
| Φ27 | 孔径 27mm | |

### 5.2 插齿刀型号

| 段 | 含义 | 示例值 |
|----|------|--------|

| m2 | 模数 2mm | |
| z50 | 齿数 50 | |
| Φ100 | 分度圆直径 | |

## 7. 数据模型映射

### 7.1 齿轮刀具在数据模型中的表达

```
CutterType:
  category = "gear_cutting"
  subcategory = "gear_hob"
  variant = "standard"

MaterialSpec:
  substrate = "hss_cobalt"    # 含钴高速钢
  coating_type = "PVD_TiAlN"
  hardness_hrc = 67.0

GeometryParams (基础，适配度低):
  diameter = 63.0             # 外径
  length = 80.0               # 滚刀宽度
  flute_length = 0.0          # 不适用
  number_of_flutes = 12       # 容屑槽数
  helix_angle = 0.0           # 不适用
  corner_radius = 0.0

GearHobGeometry (新增扩展值对象):
  module = 2.0                # 模数
  pressure_angle = 20.0       # 压力角
  number_of_starts = 1        # 头数
  hand = "right"              # 旋向
  outside_diameter = 63.0     # 外径
  bore_diameter = 27.0        # 孔径
  precision_grade = "AA"      # 精度等级
  flute_type = "straight"     # 直槽/螺旋槽
```

### 7.2 扩展需求摘要

- 齿轮刀具与现有 `GeometryParams` 适配度最低，必须使用类别专属参数
- 新增 `module`（模数）：齿轮刀具的核心参数
- 新增 `pressure_angle`（压力角）：啮合角
- 新增 `precision_grade`（精度等级）：AA/A/B/C
- 新增 `GearHobGeometry`、`GearShaperGeometry`、`GearShavingGeometry` 值对象
- 详细映射方案见 [10-数据模型映射与扩展需求](10-数据模型映射与扩展需求.md)
