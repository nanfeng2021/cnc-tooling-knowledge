# 应用场景与机床匹配需求

## 1. CNC 机床类型与加工能力

### 1.1 2 轴车床 / 车削中心

| 属性 | 说明 |
|------|------|
| 运动轴 | X/Z（+C 轴为车削中心） |
| 典型型号 | CK6136, CK6140, DMG CTX 系列 |
| 加工能力 | 外圆/内孔/端面/切槽/切断/螺纹/钻孔 |
| 对应刀具大类 | 车削、孔加工（钻/铰）、螺纹加工 |

**典型工序链**：
```
毛坯 → 粗车外圆 → 精车外圆 → 切槽 → 车螺纹 → 切断
                                     └→ 钻孔 → 铰孔
```

### 1.2 3 轴加工中心

| 属性 | 说明 |
|------|------|
| 运动轴 | X/Y/Z |
| 典型型号 | VMC850, DMG CMX 系列 |
| 加工能力 | 铣平面/台阶/槽/轮廓/钻孔/攻丝 |
| 对应刀具大类 | 铣削、孔加工、螺纹加工 |

**典型工序链**：
```
面铣大平面 → 粗铣型腔 → 精铣侧面 → 钻孔 → 攻丝
                        └→ 中心钻 → 钻 → 扩 → 铰/镗
```

### 1.3 4 轴加工中心

| 属性 | 说明 |
|------|------|
| 运动轴 | X/Y/Z + A（旋转工作台） |
| 加工能力 | 3 轴 + 旋转特征/多面加工 |
| 对应刀具大类 | 同 3 轴 + 部分齿轮刀具 |

### 1.4 5 轴联动加工中心

| 属性 | 说明 |
|------|------|
| 运动轴 | X/Y/Z + A/C（双旋转轴） |
| 典型型号 | DMU50, HAAS UMC 系列 |
| 加工能力 | 复杂曲面/叶轮/深腔/全方位加工 |
| 对应刀具大类 | 全部，尤其球头铣刀、螺纹铣刀 |

**典型工序链**：
```
粗铣型腔(高进给) → 半精铣曲面(圆鼻) → 精铣曲面(球头)
                 └→ 钻 → 铰/镗
                 └→ 螺纹铣削
```

### 1.5 车铣复合中心

| 属性 | 说明 |
|------|------|
| 运动轴 | X/Z/C + B/Y |
| 典型型号 | Mazak Integrex, DMG NLX 系列 |
| 加工能力 | 完整加工（车+铣+钻+螺纹） |
| 对应刀具大类 | 全部 |

### 1.6 专用机床

| 机床类型 | 典型型号 | 对应刀具 |
|----------|----------|----------|
| 滚齿机 | Y3150, YBA3120 | 齿轮滚刀 |
| 插齿机 | Y5120 | 插齿刀 |
| 剃齿机 | Y4232 | 剃齿刀 |
| 磨齿机 | 齿轮磨床 | 砂轮（非刀具类） |

## 2. 加工工序场景定义

### 2.1 车削工序

| 工序 | 编码 | 刀具子类 | 关键参数 | 选型要点 |
|------|------|----------|----------|----------|
| 粗车外圆 | rough_turn_external | turning_external/roughing | 大ap, 中Vc | 大截面刀杆，P30+材质 |
| 精车外圆 | finish_turn_external | turning_external/finishing | 小ap, 高Vc | Wiper刀片，P10-P15 |
| 粗车内孔 | rough_turn_internal | turning_internal/through_hole | 注意悬伸 | 短悬伸优先 |
| 精车内孔 | finish_turn_internal | turning_internal/through_hole | 小ap, 高Vc | 正前角排屑 |
| 切断 | parting_off | turning_grooving/parting | 逐步降fz | 刀宽2-4mm |
| 切槽 | grooving | turning_grooving/external | 按槽宽选刀 | 槽宽±0.1mm |
| 车外螺纹 | thread_turn_external | turning_threading/external | 多刀循环 | 全牙型刀片效率高 |
| 车内螺纹 | thread_turn_internal | turning_threading/internal | 同上 | 小径注意退刀 |

### 2.3 孔加工工序链

| 精度要求 | 工序链 | 刀具组合 | 说明 |
|----------|--------|----------|------|
| IT12-13 | 钻 | 麻花钻 | 一般精度 |
| IT10-11 | 中心钻→钻→扩 | 中心钻+麻花钻+扩孔钻 | 较高精度 |
| IT8-9 | 中心钻→钻→扩→铰 | +铰刀 | 精密孔 |
| IT6-7 | 中心钻→钻→镗 | +精镗刀 | 高精度孔 |
| IT5 | 钻→粗镗→精镗→微调镗 | +微调镗刀 | 超精密孔 |

### 2.4 螺纹加工工序

| 场景 | 推荐方式 | 刀具 | 选择依据 |
|------|----------|------|----------|
| 车床上加工外螺纹 | 螺纹车削 | 螺纹车刀 | 机床是车床 |
| 车床上加工内螺纹 | 螺纹车削/刚性攻丝 | 螺纹车刀/机用丝锥 | 小径用丝锥 |
| MC 盲孔内螺纹 | 螺旋槽丝锥/挤压丝锥 | 螺旋槽/挤压丝锥 | 盲孔排屑 |
| MC 通孔内螺纹 | 螺尖丝锥 | 螺尖丝锥 | 高效排屑 |
| MC 多规格螺纹 | 螺纹铣削 | 单刃螺纹铣刀 | 一刀多规格 |
| MC 大径内螺纹 | 螺纹铣削 | 可转位螺纹铣刀 | M30+ |
| 外螺纹（单件） | 板牙 | 圆板牙 | 现场修配 |

### 2.5 齿轮加工工序

| 目标精度 | 工序链 | 刀具组合 |

## 4. 数据模型映射

### 4.1 ApplicationScenario 值对象

```python
@dataclass(frozen=True)
class ApplicationScenario:
    machine_type: str       # 2_axis_lathe, 3_axis_mc, 4_axis_mc, 5_axis_mc,
                            # mill_turn, hobbing_machine, shaping_machine
    operation_type: str     # roughing, finishing, semi_finishing,
                            # grooving, threading, drilling, reaming,
                            # boring, tapping, thread_milling,
                            # hobbing, shaping, shaving
    strategy: Optional[str] # dynamic_milling, trochoidal, wiper, etc.
```

### 4.2 machine_type 枚举

| 编码 | 机床类型 |
|------|----------|
| 2_axis_lathe | 2 轴车床 |
| turning_center | 车削中心(+C) |
| mill_turn | 车铣复合 |
| 3_axis_mc | 3 轴加工中心 |
| 4_axis_mc | 4 轴加工中心 |
| 5_axis_mc | 5 轴联动加工中心 |
| hobbing_machine | 滚齿机 |
| shaping_machine | 插齿机 |
| shaving_machine | 剃齿机 |

### 4.3 operation_type 枚举

| 编码 | 工序类型 | 适用大类 |
|------|----------|----------|
| roughing | 粗加工 | 全部 |
| semi_finishing | 半精加工 | 全部 |
| finishing | 精加工 | 全部 |
| grooving | 切槽 | turning |
| parting_off | 切断 | turning |
| drilling | 钻孔 | hole_making |
| reaming | 铰孔 | hole_making |
| boring | 镗孔 | hole_making |
| tapping | 攻丝 | threading |
| thread_milling | 螺纹铣削 | threading |
| thread_turning | 螺纹车削 | threading |
| hobbing | 滚齿 | gear_cutting |
| shaping | 插齿 | gear_cutting |
| shaving | 剃齿 | gear_cutting |
