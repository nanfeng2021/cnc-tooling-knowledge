# 铣削刀具需求

## 1. 铣削概述

铣削加工是刀具旋转作主运动、工件（或刀具）作进给运动的切削加工方法，是 CNC 加工中心最核心的工艺。

**运动特征**：刀具旋转（主运动）+ 工件/刀具多轴进给

**适用机床**：
- 3 轴加工中心：平面/台阶/槽/轮廓/钻孔
- 4 轴加工中心：3 轴 + 旋转特征
- 5 轴联动加工中心：复杂曲面/叶轮/深腔
- 龙门铣床：大型工件平面铣削

## 2. 铣削刀具分类体系

### 2.1 立铣刀 (milling_end_mill)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 方肩立铣刀 | square | re=0，90°侧刃，可加工直角台阶 | 侧面铣削、台阶加工 |
| 球头立铣刀 | ball_nose | re=Dc/2，球面切削刃 | 曲面精加工（3轴/5轴） |
| 圆鼻立铣刀 | bull_nose | 0<re<Dc/2，兼顾方肩与球头 | 侧面/底面精加工，减少应力集中 |
| 高进给立铣刀 | high_feed | 小ap大ae，低螺旋角 | 粗加工、动态铣削、摆线铣 |
| 粗铣立铣刀 | roughing | 粗齿波形刃，大排屑空间 | 钢件粗加工，大切深 |
| 倒角立铣刀 | chamfer | 锥形切削刃，30°/45°/60°/90° | 倒角、去毛刺 |
| 微径立铣刀 | micro | Dc < 1mm，精密加工 | 微型腔、细小特征 |
| 锥度立铣刀 | taper | 带锥度的切削刃 | 模具拔模斜面、锥孔加工 |

### 2.2 面铣刀 (milling_face_mill)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 可转位面铣刀 | indexable | 机夹刀片，高效大余量 | 大平面粗精铣 |
| 焊接式面铣刀 | brazed | 焊接刀片，精加工 | 小平面精铣 |
| 密齿面铣刀 | fine_pitch | 齿距密，进给均匀 | 铸铁/钢件精铣 |
| 粗齿面铣刀 | coarse_pitch | 齿距大，排屑好 | 粗铣、断续切削 |

### 2.3 玉米铣刀 (milling_corncob)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|

| 锥度玉米铣刀 | tapered | 带锥度玉米刃 | 锥面/深腔粗加工 |

### 2.4 T型槽铣刀 (milling_t_slot)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 标准T型槽铣刀 | standard | 对称侧刃，一次成型 | T型槽加工 |

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|

| 半圆键槽铣刀 | woodruff | 特殊形状 | 半圆键槽 |

### 2.6 角度铣刀 (milling_angle)

### 2.7 成形铣刀 (milling_form)

## 3. 铣削刀具几何参数需求

### 3.1 整体立铣刀参数

| 参数 | 编码 | 单位 | 范围 | 说明 |
|------|------|------|------|------|
| 切削直径 | Dc | mm | 0.5-100 | 核心参数 |
| 总长 | L | mm | 20-300 | 刃长+柄长 |
| 刃长 | lc | mm | 2-150 | 有效切削长度 |
| 齿数 | z | - | 1-12+ | 2/3/4/6 最常见 |
| 螺旋角 | λ | ° | 0-60 | 见下方详解 |
| 圆角半径 | re | mm | 0-Dc/2 | 0=方肩, Dc/2=球头 |
| 前角 | γo | ° | -10~+15 | 正前角/负前角/零前角 |
| 柄径 | d | mm | 3-50 | 直柄/锥柄 |
| 柄型 | shank_type | - | - | 直柄/锥柄(BT/CAT/HSK) |

**螺旋角选择指南**：

| 螺旋角 | 特点 | 典型应用 |
|--------|------|----------|
| 0-15° | 高轴向力，低径向力 | 高进给铣刀、铝加工专用 |
| 25-35° | 通用 | 钢/铸铁通用加工 |
| 35-45° | 排屑好，切削平稳 | 铝合金高效加工 |
| 55-60° | 极低切削力 | 高硬度材料精加工 |

**圆角半径与立铣刀类型的关系**：

| re 值 | 刀具类型 | 说明 |
|--------|----------|------|
| re = 0 | 方肩立铣刀 (square) | 可加工直角台阶 |
| 0 < re < Dc/2 | 圆鼻立铣刀 (bull_nose) | 兼顾方肩与球头 |
| re = Dc/2 | 球头立铣刀 (ball_nose) | 曲面精加工 |

### 3.2 可转位面铣刀参数

| 参数 | 编码 | 单位 | 说明 |
|------|------|------|------|
| 刀体直径 | Dc | mm | 铣刀盘直径 |
| 刀片数 | z | - | 密齿/粗齿 |
| 齿距 | pitch | - | 密齿(fine)/普通/粗齿(coarse) |
| 刀片尺寸 | insert_size | - | 如 08/11/12/16 等 |
| 主偏角 | κr | ° | 45°/60°/75°/90° |
| 最大切深 | ap_max | mm | 取决于刀片尺寸 |

### 3.3 与现有 GeometryParams 的匹配度

铣削刀具与现有 `GeometryParams` 的匹配度最高，但需扩展：

| 参数 | 现有 GeometryParams | 需新增 | 说明 |
|------|---------------------|--------|------|
| diameter | ✅ | | 对应 Dc |
| length | ✅ | | 对应 L |
| flute_length | ✅ | | 对应 lc |
| number_of_flutes | ✅ | | 对应 z |
| helix_angle | ✅ | | 对应 λ |
| corner_radius | ✅ | | 对应 re |
| - | | shank_type | 柄型 |
| - | | insert_size | 可转位刀片尺寸 |
| - | | pitch | 面铣刀齿距 |
| - | | lead_angle | 主偏角 |

## 4. 铣削应用场景

### 4.1 机床场景匹配

| 机床类型 | 可用铣削工序 | 推荐刀具类型 |
|----------|-------------|-------------|
| 3 轴 MC | 平面/台阶/槽/轮廓/钻孔 | 方肩/面铣/键槽/钻头 |
| 4 轴 MC | 3轴 + 旋转特征 | 上述 + 特殊角度铣刀 |
| 5 轴联动 | 复杂曲面/叶轮/深腔 | 球头/圆鼻/高进给/锥度 |

### 4.2 加工策略与刀具匹配

| 加工策略 | 推荐刀具 | 关键参数 | 说明 |
|----------|----------|----------|------|
| 侧面铣削 | 方肩立铣刀 | ae=25-50%Dc, ap<1.5×Dc | 90°侧刃直角台阶 |
| 底面精加工 | 圆鼻立铣刀 | re=0.5-3mm | 底面不留刀痕 |
| 曲面精加工 | 球头立铣刀 | ae=5-15%Dc, 小ap | 3轴/5轴行切 |
| 动态铣削 | 高进给立铣刀 | ae<10%Dc, ap<2mm | 高效粗加工 |
| 大平面加工 | 面铣刀 | ae=60-80%Dc | 高效平面铣削 |
| 深槽粗加工 | 玉米铣刀 | 大径向切宽 | 分层铣削 |
| 拔模斜面 | 锥度立铣刀 | 按角度选刀 | 一次成形 |

### 4.3 切削参数推荐范围（硬质合金刀具）

| 工件材料 | Vc (m/min) | fz (mm/tooth) | ae (%Dc) | ap (mm) |

| 钢 (P) | 100-250 | 0.04-0.15 | 25-100 | 0.5-6 |
| 不锈钢 (M) | 80-200 | 0.03-0.12 | 15-50 | 0.5-4 |

| 铝合金 (N) | 300-1000 | 0.05-0.25 | 50-100 | 0.5-10 |
| 高温合金 (S) | 30-120 | 0.03-0.08 | 5-25 | 0.3-2 |
| 硬材 (H) | 80-200 | 0.03-0.08 | 5-15 | 0.1-1 |

## 5. 铣削刀具型号规则

### 5.1 整体硬质合金立铣刀

**典型格式**：`类型 直径-齿数-刃型-螺旋角-总长-柄径`

**示例**：`EDS 10.0-Z4-S-30-L75-C6`

| 段 | 含义 | 示例值 |
|----|------|--------|
| ED | End mill (立铣刀) | E=end mill |
| S | Square (方肩) | S/B/R 分别代表方肩/球头/圆鼻 |
| 10.0 | 直径 mm | Dc=10mm |
| Z4 | 4 齿 | 齿数 |
| 30 | 螺旋角 30° | λ=30° |
| L75 | 总长 75mm | L=75mm |
| C6 | 柄径 6mm | d=6mm |

### 5.2 可转位面铣刀

**示例**：`R245-125Q40-12M`

| 段 | 含义 | 示例值 |
|----|------|--------|
| R245 | 产品系列 | Sandvik CoroMill 245 |
| 125 | 刀体直径 mm | Dc=125mm |
| Q | 齿距类型 | Q=密齿, M=普通, H=粗齿 |
| 40 | 刀片数 | z=40 |
| 12 | 刀片尺寸 | 12mm |
| M | 刀片固定方式 | M=螺钉固定 |

## 7. 数据模型映射

### 7.1 铣削刀具在数据模型中的表达

```
CutterType:
  category = "milling"
  subcategory = "milling_end_mill"
  variant = "ball_nose"

MaterialSpec:
  substrate = "carbide_P30"
  coating_type = "PVD_TiAlN"
  hardness_hrc = null

GeometryParams (现有，匹配度最高):
  diameter = 10.0           # Dc
  length = 75.0             # L
  flute_length = 30.0       # lc
  number_of_flutes = 4      # z
  helix_angle = 35.0        # λ
  corner_radius = 5.0       # re = Dc/2 = 球头

MillingGeometry (新增扩展值对象):
  shank_type = "straight"   # 直柄
  insert_size = null        # 非可转位
  pitch = null              # 非面铣刀
  lead_angle = null         # 非面铣刀
```

### 7.2 扩展需求摘要

- 新增 `variant` 字段到 `CutterType`
- 新增 `MillingGeometry` 值对象（shank_type, insert_size, pitch, lead_angle）
- 铣削刀具的 `GeometryParams` 利用度最高，新增参数为可选扩展
- 详细映射方案见 [10-数据模型映射与扩展需求](10-数据模型映射与扩展需求.md)
