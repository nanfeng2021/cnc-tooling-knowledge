# 孔加工刀具需求

## 1. 孔加工概述

孔加工是 CNC 加工中最常见的工序之一，几乎所有工件都涉及孔的加工。孔加工按精度和工序可分为钻孔、扩孔、铰孔、镗孔、锪孔等。

**运动特征**：刀具旋转（主运动）+ 刀具轴向进给

**适用机床**：所有 CNC 机床均具备孔加工能力（2轴车床、3/4/5轴加工中心、车铣复合）

## 2. 孔加工刀具分类体系

### 2.1 钻头 (hole_drill)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 麻花钻 | twist | 标准螺旋槽，通用最广 | 通用钻孔，HSS/硬质合金 |
| 中心钻 | center_drill | 短而粗，带护锥 | 加工中心孔（定位基准） |
| 定心钻 | spot_drill | 短刃，90°/120°顶角 | 钻前定心，防止钻偏 |
| 扩孔钻 | core_drill | 3-4槽，导向好 | 钻后扩孔，提高精度 |
| 阶梯钻 | step_drill | 多段直径 | 一次加工多段孔 |
| 可转位钻头 | indexable_drill | 机夹刀片，高效 | 大孔径高效钻孔 Φ15-80 |
| 深孔钻 | gun_drill | 单槽，内冷 | 长径比 >5 的深孔 |
| 硬质合金定柄钻 | solid_carbide_drill | 整体硬质合金，高精度 | 高速高效钻孔 |

### 2.2 铰刀 (hole_reamer)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 直槽铰刀 | straight | 直槽，精密导向 | 通用铰孔 |
| 螺旋槽铰刀 | spiral | 螺旋槽，排屑好 | 盲孔/断续孔铰孔 |
| 锥度铰刀 | taper | 锥形刃，莫氏/1:50 等 | 锥孔精加工 |
| 可调铰刀 | adjustable | 可微调直径 | 特殊孔径铰孔 |
| 机用铰刀 | machine | 机夹式，高效 | CNC 机床铰孔 |
| 手用铰刀 | hand | 手动操作，高精度 | 修配/小批量铰孔 |

### 2.3 镗刀 (hole_boring)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 粗镗刀 | rough_boring | 双刃，高效去除余量 | 粗镗孔 |
| 精镗刀 | fine_boring | 单刃微调，高精度 | IT6-IT7 精度孔 |
| 微调镗刀 | micro_boring | 0.001mm 级调节 | IT5 精度精密孔 |
| 双刃镗刀 | double_edge | 对称双刃，平衡切削 | 大径孔高效镗削 |

### 2.4 锪钻 (hole_countersink)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 沉头锪钻 | countersink | 锥面刃，60°/82°/90°/120° | 沉头螺钉孔锥面 |
| 锪平面钻 | counterbore | 端面刃，圆柱导向 | 锪平面/沉孔 |

## 3. 孔加工刀具几何参数需求

### 3.1 钻头参数

| 参数 | 编码 | 单位 | 范围 | 说明 |
|------|------|------|------|------|
| 直径 | Dc | mm | 0.5-80 | 钻头标称直径 |
| 总长 | L | mm | 10-300 | 含柄部长度 |
| 有效长 | lef | mm | 5-200 | 可钻深度 |
| 螺旋角 | λ | ° | 25-45 | 影响排屑和刚性 |
| 顶角 | point_angle | ° | 90-140 | 118°通用/135°硬材/90°铝 |
| 横刃厚 | web_thickness | mm | - | 影响定心 |
| 钻芯厚度 | - | mm | - | 影响刚性 |
| 槽长 | flute_length | mm | - | 排屑槽长度 |

**顶角选择指南**：

| 顶角 | 适用材料 | 说明 |
|------|----------|------|
| 90° | 铝合金、塑料 | 薄切屑，低力 |
| 118° | 通用（钢、铸铁） | 最常见标准顶角 |
| 130° | 不锈钢 | 改善排屑 |
| 135° | 硬材、高温合金 | 分屑效果好 |
| 140° | 高硬度钢 | 细长钻头 |

### 3.2 铰刀参数

| 参数 | 编码 | 单位 | 范围 | 说明 |

| 直径 | Dc | mm | 1-100 | 含公差 |

| 槽数 | z | - | 4/6/8 | 偶数常见 |

| 槽型 | flute_type | - | straight/spiral | 直槽/螺旋槽 |

## 4. 孔加工应用场景

### 4.1 工序链推荐

孔加工精度等级与工序链的对应关系：

| 孔精度 | 工序链 | 说明 |
|--------|--------|------|
| IT12-IT13 | 钻 | 一般精度孔 |
| IT10-IT11 | 钻 → 扩 | 较高精度 |
| IT8-IT9 | 钻 → 扩 → 铰 | 精密孔 |
| IT6-IT7 | 钻 → 扩 → 镗 | 高精度孔 |
| IT5 | 钻 → 粗镗 → 精镗 → 微调镗 | 超精密孔 |

### 4.2 机床场景匹配

| 机床类型 | 可用孔加工方式 | 推荐刀具 |
|----------|---------------|----------|
| 2 轴车床 | 中心钻/钻/铰（工件旋转） | 直柄钻头、机用铰刀 |
| 3 轴 MC | 全部孔加工方式 | 全系列孔加工刀具 |
| 5 轴 MC | 全部 + 任意角度孔 | 全系列 + 角度头适配 |
| 车铣复合 | 车削+铣削孔加工 | 车削内孔刀 + 钻/铰/镗 |

### 4.3 切削参数推荐范围

**钻削参数**：

| 工件材料 | Vc (m/min) | fn (mm/rev) | 备注 |
|----------|------------|-------------|------|
| 钢 (P) | 30-80 | 0.05-0.30 | HSS: 低值, 硬质合金: 高值 |
| 不锈钢 (M) | 15-40 | 0.05-0.20 | 需充分冷却 |
| 铸铁 (K) | 40-120 | 0.08-0.35 | 硬质合金可达高值 |

## 5. 孔加工刀具型号规则

### 5.1 麻花钻型号

**HSS 麻花钻**：`B {直径} {槽型} {螺旋角} {总长}`

示例：`B6.0S-30L60`（Φ6mm 直柄标准麻花钻，30°螺旋角，60mm 总长）

**硬质合金钻头**（Sandvik CoroDrill 860 格式）：

示例：`860.1-1000-012A0-PM 4240`

| 段 | 含义 | 示例值 |
|----|------|--------|
| 860.1 | 产品系列 | CoroDrill 860 |
| 1000 | 直径 ×100 | Dc=10.0mm |
| 012 | 有效长 ×10 | lef=12mm |
| A0 | 槽型代号 | A=标准 |
| PM | 断屑槽代号 | PM=钢精加工 |
| 4240 | 材质代号 | Sandvik 牌号 |

### 5.2 铰刀型号

示例：`830A-1200-H7`（Φ12mm H7 级铰刀）

### 5.3 镗刀型号

示例：`EWN 40-50`（精镗头，加工范围 Φ40-50mm）

## 7. 数据模型映射

### 7.1 孔加工刀具在数据模型中的表达

```
CutterType:
  category = "hole_making"
  subcategory = "hole_drill"
  variant = "twist"

MaterialSpec:
  substrate = "carbide_K20"
  coating_type = "PVD_TiAlN"
  hardness_hrc = null

GeometryParams (基础):
  diameter = 6.0            # Dc
  length = 60.0             # L
  flute_length = 30.0       # 槽长
  number_of_flutes = 2      # 麻花钻 2 槽
  helix_angle = 30.0        # λ
  corner_radius = 0.0

DrillingGeometry (新增扩展值对象):
  point_angle = 118.0       # 顶角
  web_thickness = null      # 横刃厚
  tolerance_class = null    # 非铰刀
  bore_diameter_min = null  # 非镗刀
  bore_diameter_max = null  # 非镗刀
  adjustment_precision = null
```

### 7.2 扩展需求摘要

- 新增 `DrillingGeometry` 值对象：point_angle, web_thickness
- 新增 `ReamingGeometry` 值对象：tolerance_class, chamfer_angle, guide_length
- 新增 `BoringGeometry` 值对象：bore_diameter_min/max, adjustment_precision
- 钻头顶角 (point_angle) 是钻头区别于其他刀具的关键参数，必须新增
- 铰刀公差等级 (tolerance_class) 是铰刀选型的核心依据
- 镗刀孔径范围 (bore_diameter_min/max) 是镗刀选型的核心参数
- 详细映射方案见 [10-数据模型映射与扩展需求](10-数据模型映射与扩展需求.md)
