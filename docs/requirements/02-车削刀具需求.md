# 车削刀具需求

## 1. 车削概述

车削加工是工件旋转作主运动、车刀作进给运动的切削加工方法，是 CNC 加工中最基础也最广泛应用的工艺。

**运动特征**：工件旋转（主运动）+ 刀具直线/曲线进给

**适用机床**：
- 2 轴车床（X/Z 轴）：基础车削
- 车削中心（+C 轴）：车削 + 端面铣/钻孔
- 车铣复合（+B/Y 轴）：完整加工

## 2. 车削刀具分类体系

### 2.1 外圆车刀 (turning_external)

| 变型 | 编码 | 特点 | 典型刀片 |
|------|------|------|----------|
| 粗车外圆刀 | roughing | 大切深、高效率，负前角刀片 | CNMG, WNMG |
| 精车外圆刀 | finishing | 小切深、高精度，正前角刀片 | DNMG, VNMG |
| 轻切削外圆刀 | light | 小型工件、低刚性，小截面刀杆 | CCMT, DCMT |
| 重切削外圆刀 | heavy | 大型工件、大切深，大截面刀杆 | RNNG, SNMM |
| 小型外圆刀 | miniature | 微小径工件、精密加工 | VCMT, DCGT |

### 2.2 内孔车刀 (turning_internal)

| 变型 | 编码 | 特点 | 典型应用 |
|------|------|------|----------|
| 通孔车刀 | through_hole | 刀杆悬伸短，刚性较好 | 直通内孔加工 |
| 盲孔车刀 | blind_hole | 刀片偏置，需正前角排屑 | 阶梯孔、盲孔底部 |
| 微小径内孔车刀 | micro | 刀杆直径 < 10mm | 小径深孔精加工 |

### 2.3 端面车刀 (turning_facing)

| 变型 | 编码 | 特点 | 典型刀片 |
|------|------|------|----------|
| 外端面车刀 | external | 从外向内车端面 | WNMG, SNMG |
| 内端面车刀 | internal | 从内向外车端面（内孔肩面） | CCMT, DCMT |

### 2.4 切断刀/切槽刀 (turning_grooving)

| 变型 | 编码 | 特点 | 典型槽宽 |
|------|------|------|----------|
| 切断刀 | parting | 切断工件，全深度切削 | 2-6mm |
| 外圆切槽刀 | external | 外圆环槽加工 | 2-8mm |
| 内孔切槽刀 | internal | 内孔环槽加工 | 2-6mm |
| 端面切槽刀 | face | 端面环形槽加工 | 2-8mm |
| 窄槽刀 | narrow | O 型圈槽等精密窄槽 | 1-3mm |
| 宽槽刀 | wide | 多刀拼接宽槽加工 | 6-25mm |

### 2.5 螺纹车刀 (turning_threading)

| 变型 | 编码 | 特点 | 典型刀片 |
|------|------|------|----------|
| 外螺纹车刀 | external | 外螺纹车削 | 16ER, 11ER |
| 内螺纹车刀 | internal | 内螺纹车削 | 11IR, 16IR |
| 管螺纹车刀 | pipe | 管螺纹（BSPT/NPT）车削 | 特制刀片 |

### 2.6 仿形车刀 (turning_profiling)

| 变型 | 编码 | 特点 | 典型刀片 |
|------|------|------|----------|
| 粗仿形车刀 | rough | 粗仿形，大切深 | DNMG, VNMG |
| 精仿形车刀 | finish | 精仿形，高光洁度 | DCGT, VCGT |

## 3. 车削刀具几何参数需求

### 3.1 可转位刀片参数

**刀片形状（ISO 1832 第一位）**：

| 代号 | 形状 | 刀尖角 | 典型应用 |
|------|------|--------|----------|
| C | 菱形 80° | 80° | 外圆/端面粗精车 |
| D | 菱形 55° | 55° | 仿形车削 |
| E | 六边形 | 60° | 仿形精加工 |
| K | 平行四边形 | 55° | 仿形车削 |
| M | 菱形 86° | 86° | 轻切削 |
| R | 圆形 | - | 粗车/仿形 |
| S | 正方形 | 90° | 端面/外圆粗车 |
| T | 三角形 | 60° | 外圆/端面 |
| V | 菱形 35° | 35° | 精仿形 |
| W | 六边形 80° | 80° | 外圆/端面粗精车 |

**后角（ISO 1832 第二位）**：

| 代号 | 后角 | 说明 |
|------|------|------|
| N | 0° | 最常用，负前角加工 |
| B | 5° | 正前角轻切削 |
| C | 7° | 正前角精加工 |
| E | 20° | 铝合金等软材料 |
| P | 11° | 通用正前角 |

**刀杆截面**：

| 类型 | 说明 | 典型规格 |
|------|------|----------|
| 正方形 | 刚性最好 | 20×20, 25×25, 32×32 |
| 矩形 | 常用 | 25×16, 32×20 |
| 圆形 | 内孔车刀 | Φ16, Φ20, Φ25 |

**切削方向**：

| 代号 | 说明 |
|------|------|
| R | 右切（从右向左） |
| L | 左切（从左向右） |
| N | 双向 |

### 3.2 车削几何参数与铣削的差异

车削刀具几何参数与现有 `GeometryParams`（铣削专属）差异显著：

| 参数 | 车削需求 | 现有 GeometryParams | 适配性 |
|------|----------|---------------------|--------|
| 刀片形状 | insert_shape (C/D/S/T/...) | 无 | 需新增 |
| 刀片尺寸 | insert_ic (内切圆) | 无 | 需新增 |
| 后角 | relief_angle (N/B/C/E/P) | 无 | 需新增 |
| 刀杆截面 | holder_section (20×20等) | 无 | 需新增 |
| 切削方向 | hand (R/L/N) | 无 | 需新增 |
| 螺旋角 | - | helix_angle | 车削不需要 |
| 齿数 | - | number_of_flutes | 车削不需要 |
| 刃长 | - | flute_length | 车削用悬伸长 |

## 5. 车削刀具可转位刀片型号规则

### 5.1 ISO 1832 标准编码

**格式**：`形状 后角 精度 断屑槽 刃长 厚度 刀尖圆弧 - 断屑槽代号 材质代号`

**示例**：`CNMG 120408-PM 4325`

| 位号 | 含义 | 示例值 | 说明 |
|------|------|--------|------|
| 1 | 刀片形状 | C | 菱形 80° |
| 2 | 后角 | N | 0° |
| 3 | 精度 | M | ±0.08-0.13mm |
| 4 | 固定方式/断屑槽 | G | 有断屑槽，单面 |
| 5 | 刃长 | 12 | 12mm |
| 6 | 厚度 | 04 | 4mm |
| 7 | 刀尖圆弧 | 08 | 0.8mm |
| 8 | 断屑槽代号 | PM | 钢精加工 |
| 9 | 材质代号 | 4325 | Sandvik 牌号 |

### 5.2 各厂商编码对照

| 厂商 | 示例型号 | 差异说明 |
|------|----------|----------|
| Sandvik | CNMG 120408-PM 4325 | 断屑槽代号体系（PM/MM/KM等） |
| Kennametal | CNMG 120408KC KCP10 | 断屑槽代号+材质代号不同 |
| ZCC | CNMG 120408-PM YB6315 | 国产材质代号 |
| Mitsubishi | CNMG 120408 UC5115 | 断屑槽代号体系不同 |

## 7. 数据模型映射

### 7.1 车削刀具在数据模型中的表达

```
CutterType:
  category = "turning"
  subcategory = "turning_external"
  variant = "roughing"

MaterialSpec:
  substrate = "carbide_P25"
  coating_type = "PVD_TiAlN"
  hardness_hrc = null

TurningGeometry (新增值对象):
  insert_shape = "C"          # 菱形 80°
  insert_ic = 12.7            # 内切圆直径 mm
  relief_angle = "N"          # 0°
  holder_section = "25×25"    # 刀杆截面
  hand = "R"                  # 右切
  overhang = 40               # 悬伸长度 mm
```

### 7.2 扩展需求摘要

- 新增 `variant` 字段到 `CutterType`
- 新增 `TurningGeometry` 值对象（刀片形状、内切圆、后角、刀杆截面、切削方向、悬伸长）
- 车削刀具的 `GeometryParams` 仅填充 diameter（刀片内切圆）和 length（刀杆长度）
- 详细映射方案见 [10-数据模型映射与扩展需求](10-数据模型映射与扩展需求.md)
