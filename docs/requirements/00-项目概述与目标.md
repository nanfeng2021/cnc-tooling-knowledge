# 项目概述与目标

## 1. 项目定位

CNC 刀具知识库是一个面向 CNC 编程人员与工艺工程师的 RAG（Retrieval-Augmented Generation）智能刀具知识库系统。核心目标是**汇总数控机床各种刀具刀头的分类、应用场景、厂商等信息**，通过自然语言查询实现精准的刀具推荐与切削参数匹配。

### 核心价值主张

```
自然语言查询 → 精准刀具推荐 + 切削参数 + 厂商对比
```

## 2. 目标用户画像

| 用户类型 | 典型场景 | 核心诉求 |
|----------|----------|----------|
| CNC 编程工程师 | 编写加工程序时选刀 | 快速找到适合加工特征和材料的刀具 |
| 工艺规划工程师 | 编制工艺路线时选型 | 获取切削参数、工序链推荐 |
| 刀具采购/选型人员 | 厂商对比与采购决策 | 跨厂商同类型刀具参数对比 |
| 数控操作技师 | 现场换刀/参数调整 | 查询特定刀具的推荐参数 |

## 3. 核心功能需求

### 3.1 语义搜索

**需求描述**：用户使用自然语言描述加工需求，系统返回匹配的刀具列表。

**输入示例**：
- "加工45号钢外圆，粗车"
- "ball nose end mill for aluminum"
- "M8螺纹孔，盲孔攻丝"

**输出**：匹配刀具列表 + 相关度评分 + 推荐切削参数

### 3.2 切削参数推荐

**需求描述**：根据工件材料和加工工序，推荐切削速度(Vc)、进给量(fz/fn)、切深(ap/ae)等参数。

**规则**：
- 参数按刀具材质 + 涂层 + 工件材料组合推荐
- 区分粗加工/半精加工/精加工不同工况
- 提供参数范围而非单一值

### 3.3 刀具选型

**需求描述**：根据加工特征（外圆/内孔/槽/螺纹等）和工件材料，推荐合适的刀具类型和具体型号。

**选型要素**：
- 加工特征 → 刀具大类/子类
- 工件材料 → 刀片材质 + 涂层
- 精度要求 → 刀具类型细分
- 机床类型 → 刀具接口适配

### 3.4 厂商对比

**需求描述**：对同类型刀具进行跨厂商参数对比。

**对比维度**：
- 切削性能参数（Vc, fz）
- 刀片材质与涂层
- 价格区间
- 供货周期
- 适用工况

## 6. 术语表

| 术语 | 定义 |
|------|------|
| 刀具大类 (category) | 一级分类，对应主要加工方式（车/铣/钻/螺纹/齿轮） |
| 刀具子类 (subcategory) | 二级分类，对应具体刀具形态（立铣刀/面铣刀/麻花钻等） |
| 刀具变型 (variant) | 三级分类，对应功能细分（球头/方肩/高进给等） |
| 可转位刀片 (Indexable Insert) | 机械夹固在刀杆上的刀片，磨损后可转位或更换 |
| 整体刀具 (Solid Tool) | 切削部分与刀体为一体的刀具 |
| 涂层 (Coating) | 通过 PVD/CVD 在刀具表面沉积的硬质薄膜 |
| Vc | 切削速度，单位 m/min |
| fz | 每齿进给量，单位 mm/tooth |
| ap | 轴向切深，单位 mm |
| ae | 径向切宽，单位 mm |
| HRC | 洛氏硬度 C 标尺，用于衡量材料硬度 |
