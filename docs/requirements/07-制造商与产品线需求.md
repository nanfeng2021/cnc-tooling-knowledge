# 制造商与产品线需求

## 1. 制造商信息模型设计

### 1.1 制造商实体属性

| 属性 | 编码 | 类型 | 说明 |
|------|------|------|------|
| 标识 | id | UUID | 唯一标识 |
| 中文名 | name_zh | str | 中文注册名称 |
| 英文名 | name_en | str | 英文/原文名称 |
| 国别 | country | str | 总部所在国 |
| 官网 | website | str | 官方网站 |
| 主营类别 | specialties | list[str] | 主要产品类别 |
| 简介 | description | str | 厂商简介 |

### 1.2 产品线实体属性

| 属性 | 编码 | 类型 | 说明 |
|------|------|------|------|
| 标识 | id | UUID | 唯一标识 |
| 制造商ID | manufacturer_id | UUID | 关联制造商 |
| 中文名 | name_zh | str | 产品线中文名 |
| 英文名 | name_en | str | 产品线英文名 |
| 所属大类 | category | str | turning/milling/hole_making/threading/gear_cutting |
| 技术特点 | features | list[str] | 核心技术特点 |
| 适用场景 | applicable_scenarios | list[str] | 适用加工场景 |
| 型号编码规则 | model_pattern | str | 型号编码正则/格式 |

### 1.3 型号编码解析规则

| 属性 | 编码 | 类型 | 说明 |
|------|------|------|------|
| 编码格式 | pattern_format | str | 编码各段格式定义 |
| 各段含义 | segment_definitions | list[dict] | 每段的名称/类型/取值范围 |
| 解析示例 | parse_examples | list[dict] | 示例型号及其解析结果 |

**型号编码规则（ISO 1832 车削刀片）**：

```
CNMG 120408-PM 4325
││││  └└└└ └─ 断屑槽代号(PM=钢精加工) + 材质代号(4325)
││││  │││└── 刀尖圆弧 08=0.8mm
││││  ││└─── 厚度 04=4mm
││││  └└──── 刃长 12=12mm
│││└─── 固定方式/断屑槽 G=有断屑槽
││└──── 精度 M=±0.08-0.13mm
│└───── 后角 N=0°
└────── 形状 C=菱形80°
```

**材质代号体系**：

| 材质代号 | ISO 分类 | 特点 |
|----------|----------|------|
| 4325 | P25-P35 | 钢件通用 |
| 4345 | P35-P45 | 钢件粗加工 |
| 1125 | P10-P25 | 钢件精加工 |
| 2025 | M20-M30 | 不锈钢通用 |
| 3225 | K20-K30 | 铸铁通用 |
| GC 1115 | P05-P15 | 钢件高速精加工 |

## 4. 厂商信息与数据模型映射

### 4.1 新增实体

```
Manufacturer:
  id: UUID
  name_zh: "山特维克可乐满"
  name_en: "Sandvik Coromant"
  country: "瑞典"
  website: "www.sandvik.coromant.com"
  specialties: ["turning", "milling", "hole_making", "threading"]
  description: "全球刀具行业领导者"

ProductLine:
  id: UUID
  manufacturer_id: UUID
  name_zh: "CoroTurn Prime"
  name_en: "CoroTurn Prime"
  category: "turning"
  features: ["高进给", "Wiper刀片"]
  applicable_scenarios: ["钢件高效车削"]
  model_pattern: "ISO 1832 + Sandvik材质代号"
```

### 4.2 Cutter 聚合根关联

```
Cutter:
  manufacturer_id: UUID          # 新增：关联制造商
  model_number: "CNMG 120408-PM 4325"  # 新增：厂商型号
```

### 4.3 扩展需求摘要

- 新增 `Manufacturer` 实体
- 新增 `ProductLine` 实体
- `Cutter` 聚合根增加 `manufacturer_id` 和 `model_number` 字段
- 型号编码解析器：将型号字符串自动解析为刀具参数
- 详细映射方案见 [10-数据模型映射与扩展需求](10-数据模型映射与扩展需求.md)
